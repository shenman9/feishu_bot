# 文件阅读插件

## 简介

支持用户上传 `.txt` 文本文件，机器人读取文件内容后以文本形式返回。适用于快速查看纯文本文件内容，或将文件内容传递给其他插件处理。

## 触发方式

在飞书聊天中发送关键词 `文件阅读` 即可激活插件。

## 功能特性

- 接收用户上传的 `.txt` 文件并读取内容
- 自动检测 UTF-8 / GBK 编码，兼容中文文件
- 维护当次会话内的文件历史，支持输入编号重新查看已上传文件
- 文件大小限制：100 KB
- 仅支持 `.txt` 格式（拒绝其他类型并给出提示）

## 使用流程

```
用户: 文件阅读
机器人: 已进入文件阅读模式，请上传 .txt 文件。

用户: [上传 notes.txt]
机器人: 文件名：notes.txt
        内容：
        --------
        （文件正文...）
        --------
        已上传 1 个文件，输入编号（如 1）可重新查看。

用户: 1
机器人: 文件名：notes.txt
        内容：...

用户: 退出
机器人: 已退出文件阅读模式。
```

## 文件结构

```
file_reader/
├── __init__.py             # 导出 FileReaderPlugin
└── file_reader_plugin.py   # 插件主体实现（128 行）
```

## 主要实现

| 类/方法 | 说明 |
|--------|------|
| `FileReaderPlugin` | 插件主类 |
| `handle_message()` | 处理文本消息（数字编号重新查看文件）|
| `handle_file_message()` | 处理文件消息（下载、读取、返回内容）|
| `is_user_active()` | 返回用户是否处于活跃会话中 |

## 限制说明

| 项目 | 限制 |
|------|------|
| 文件类型 | 仅 `.txt` |
| 文件大小 | 最大 100 KB |
| 编码支持 | UTF-8、GBK |

## 配置

无需额外配置，开箱即用。

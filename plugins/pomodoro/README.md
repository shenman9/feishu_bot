# 番茄钟插件

## 简介

番茄钟计时器插件，支持单次/多周期番茄钟、工作-休息循环、暂停/恢复/跳过/停止等灵活的计时控制。使用 APScheduler 作为调度引擎，计时器在后台独立运行，切换到其他插件后仍会正常通知。

## 触发方式

在飞书聊天中发送关键词 `番茄钟` 即可进入设置界面。

## 功能特性

- 自定义工作时长（时/分/秒精度）、休息时长、周期数
- 自定义番茄钟标题（如"写代码"、"阅读"）
- 多周期模式：工作→休息→工作→休息 循环
- 每个阶段结束后等待用户手动确认开始下一阶段
- 运行中支持暂停/恢复/跳过/停止
- 跳过休息直接进入下一轮工作
- 卡片实时刷新剩余时间（每 5 秒更新）
- 阶段结束时发送飞书加急通知
- 完成后可"再来一轮"（累加周期，延续统计）
- 记忆上次设置参数，返回设置页时自动回显
- 专注统计：按用户维度跨群聊统计今日/累计专注时间、完成周期数
- 统计数据持久化到磁盘，重启不丢失
- 按 (user_id, chat_id) 隔离，不同群聊独立运行
- 切换到其他插件后计时器继续运行，到期照常通知

## 使用流程

```
用户: 番茄钟
机器人: [设置卡片：标题、工作时长(时/分/秒)、休息时长(时/分/秒)、周期数]

用户: [填写参数，点击「开始」]
机器人: [运行中卡片：标题 · 剩余时间，实时刷新]
        按钮: [暂停] [跳过] [停止]

（工作时间到）
机器人: [等待卡片：工作时间结束！]
        按钮: [开始休息] [跳过休息] [停止]

用户: [点击「开始休息」]
机器人: [运行中卡片：休息 · 剩余时间]

（休息结束）
机器人: [等待卡片：休息结束！第 2/4 轮即将开始]
        按钮: [开始工作] [停止]

（所有轮次完成）
机器人: [完成卡片：统计信息]
        按钮: [再来一轮] [返回]
```

## 文本指令

| 指令 | 作用 |
|------|------|
| `番茄钟` / `菜单` | 打开设置界面 |
| `专注` | 开始 25 分钟番茄钟（默认） |
| `专注 30` | 开始 30 分钟番茄钟 |
| `暂停` | 暂停当前计时 |
| `恢复` / `继续` | 恢复计时 |
| `停止` | 停止番茄钟 |
| `跳过` | 跳过当前阶段 |
| `状态` | 查看番茄钟状态 |

## 文件结构

```
plugins/pomodoro/
├── __init__.py            # 导出 PomodoroPlugin
├── models.py              # 数据模型：Phase、PomodoroState、DailyStats、LastSettings、UserTimers
├── cards.py               # 飞书卡片构建函数（纯函数，无状态）
├── stats.py               # 专注统计持久化模块（按用户存储到 stats/ 目录）
└── pomodoro_plugin.py     # 主插件类：调度器管理、状态机、卡片动作处理
config/pomodoro.yaml.example  # 配置示例
```

## 主要实现

| 类/方法 | 说明 |
|--------|------|
| `PomodoroPlugin` | 插件主类 |
| `_start_pomodoro()` | 启动番茄钟，返回卡片 dict |
| `_on_phase_end()` | 阶段结束回调（APScheduler 调用） |
| `_pause_pomodoro()` | 暂停计时，记录剩余时间 |
| `_resume_pomodoro()` | 恢复计时，回拨 phase_start_time |
| `_skip_phase()` | 跳过当前阶段 |
| `_stop_pomodoro()` | 停止番茄钟 |
| `_start_next_phase()` | 用户确认开始下一阶段 |
| `_skip_rest()` | 跳过休息进入下一轮 |
| `_refresh_card()` | 定时刷新卡片剩余时间 |

## 状态说明

| 状态 | 含义 |
|------|------|
| `idle` | 空闲，无番茄钟 |
| `running` | 计时中 |
| `paused` | 已暂停 |
| `waiting` | 阶段结束，等待用户确认开始下一阶段 |
| `completed` | 所有周期完成 |

## 时间管理机制

存储 3 个值：`phase_start_time`（阶段虚拟起点）、`remaining_seconds`（暂停时的剩余时间）、`work_seconds`/`rest_seconds`（设定时长）。

核心公式：`剩余时间 = phase_duration - (now - phase_start_time)`

恢复计时时回拨 `phase_start_time = now - (duration - remaining)`，使公式自然得出正确的剩余时间，无需额外字段。

## 配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `default_work_minutes` | 25 | 默认工作时长（分钟） |
| `default_rest_minutes` | 5 | 默认休息时长（分钟） |
| `default_cycles` | 4 | 默认多周期数 |

当前版本使用内存默认值，配置文件为可选（`config/pomodoro.yaml`）。

## 依赖

- `apscheduler>=3.10`（APScheduler，后台定时调度）

## 注意事项

- 番茄钟状态存储在内存中，服务重启后丢失
- 每个 (user_id, chat_id) 最多同时运行一个番茄钟
- 卡片每 5 秒刷新一次剩余时间，通过 `patch_message` API 更新
- 所有卡片按钮包含 `"plugin": "番茄钟"` 字段，确保切换插件后按钮仍能正确路由
- 阶段结束后不自动开始下一阶段，等待用户手动确认
- `rest_seconds=0` 时跳过休息阶段，直接进入下一轮工作

# 石头剪刀布插件

## 简介

与机器人进行石头剪刀布（猜拳）对战的互动小游戏。机器人每轮随机出拳，用户通过飞书卡片按钮选择出拳，最终显示胜负结果。

## 触发方式

在飞书聊天中发送关键词 `石头剪刀布` 即可进入游戏。

## 功能特性

- 通过交互式卡片按钮出拳，操作直观
- 机器人随机出拳，保证公平性
- 结果以 Emoji 展示，并用颜色区分胜负（绿色=赢、红色=输、黄色=平）
- 支持多轮连续对战，每轮结束后自动开始下一轮
- 发送 `结束` 可随时退出游戏

## 使用流程

```
用户: 石头剪刀布
机器人: [出拳卡片，含三个按钮：石头 / 剪刀 / 布]

用户: [点击「石头」]
机器人: 你出了 ✊ 石头
        我出了 ✌️ 剪刀
        🎉 你赢了！
        [继续出拳的卡片]

用户: 结束
机器人: 游戏结束，下次见！
```

## 文件结构

```
rps_game/
├── __init__.py       # 导出 RPSPlugin
└── rps_plugin.py     # 插件主体实现（154 行）
```

## 主要实现

| 类/方法 | 说明 |
|--------|------|
| `RPSPlugin` | 插件主类 |
| `handle_message()` | 处理文本消息（游戏开始、结束指令）|
| `handle_card_action()` | 处理卡片按钮点击（用户出拳）|
| `is_user_active(user_id, chat_id)` | 返回用户是否正在游戏中 |

## 配置

无需额外配置，开箱即用。
